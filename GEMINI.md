# Autopilot & Autonomous Execution Rule

## Directives
- **Full Autopilot Execution**: Execute all implementation steps, build commands, file deletions, refactoring, and deployments automatically without requesting permission for routine actions.
- **Proactive Problem Solving**: If any build warning, missing dependency, or configuration issue arises, resolve it immediately and verify the fix.
- **Continuous Deployment**: Always build and deploy to GitHub Pages (`gh-pages`) upon completing tasks so live changes reflect immediately.
